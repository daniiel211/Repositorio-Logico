Sistema de Gestión Logística

LogiCo es un sistema web desarrollado en Django para automatizar los procesos logísticos de Discopro Ltda., empresa que presta servicios de despacho a domicilio para farmacias Cruz Verde.

Características Principales
  • Gestión completa de farmacias, motoristas y vehículos
  • Sistema de asignaciones dinámicas
  • Control de movimientos y entregas
  • Sistema de rangos geográficos
  • Reportes y dashboard en tiempo real
  • Interfaz responsive con Bootstrap 5
